# Creator Economy

## 1. 核心角色
- Contributor / Creator
- Learner
- Platform

## 2. 可交易资产
- Knowledge Pack
- Narrative Pack
- Experience Pack
- Route Pack

## 3. 商业原则

优秀导游的职业经验应被视为可授权、可复用、可持续产生收益的数字资产。

平台不是鼓励“多上传”，而是奖励经过真实带团验证的有效价值。

每项音频或文案由贡献者明确选择：保持私有、仅供公众学习、参与商业共享并
获得贡献奖励，或同时开放公众学习与商业共享。公众学习授权不等于商业授权；
商业共享必须绑定奖励接收人并进入 Contribution Ledger。

## 4. Creator 奖励来源

至少包括：
- 销售分成
- 订阅使用分成
- 真实带团使用奖励
- 质量奖励
- 高复用/高留存奖励
- 低纠错率奖励
- 稀缺区域奖励
- 稀缺语言奖励
- 区域冷启动奖励
- 有效更新/纠错奖励

## 5. Contribution Ledger

即使贡献者没有制作完整Pack，也可以记录小贡献：
- factual correction
- new experience
- new branch storyline
- language correction
- new route note
- photography / viewing advice
- local operating change
- official rule update

每条贡献保留：
- author
- source / evidence
- region
- language
- route/place/topic scope
- created_at
- validation state
- real-use count
- correction count
- rating / usefulness signals

## 6. 分成基线

初始商业假设：
- Contributor: 70%
- Platform: 30%

分配基数为扣除支付通道、税费、退款后的可分配净收入。

正式上线前按区域税务、支付费率、退款和Contributor结算规则校准。

优秀创作者未来可采用成长型分成，例如：
- Contributor: 70%
- Verified Guide Creator: 75%
- Expert Creator: 80%
- Master / 独家内容：单独协议

以上比例均为产品商业假设，不是不可修改的宪法条款。

## 7. Creator 等级
- Contributor
- Verified Guide Creator
- Expert Creator
- Master Guide

等级不能单靠上传数量获得，应结合真实使用、质量、留存、纠错率、专业验证和用户反馈。

## 8. 区域扩张

新区域采用 Creator Seed Program 冷启动：
- 首批当地专业导游
- 首批重点路线
- 首批稀缺语言
- 更高早期激励
- 官方推荐位
- 区域首批Creator身份

目标：Global Core + Local Expert Supply，而不是平台自己从零编辑全世界。
