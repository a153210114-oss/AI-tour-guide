# Melbourne Claim-to-Source Ledger

The machine-readable claim ledger is
`04_Knowledge/packs/melbourne_knowledge_seed_r1.json`. Each node records claim, publisher,
source title, canonical URL and source grade. Access date for this research wave is
2026-09-06 unless a node is later superseded.

Primary source families:

- City routes and civic places: City of Melbourne / What's On Melbourne.
- Parks, closures and nature: Parks Victoria and Royal Botanic Gardens Victoria.
- Museums and migration: Museums Victoria and ACMI.
- Libraries and historical timelines: State Library Victoria.
- Parliament and memorial history: Parliament of Victoria and Shrine of Remembrance.
- Regional route structure: Visit Victoria.
- Image rights: individual Wikimedia Commons file pages; never category-level assumptions.
