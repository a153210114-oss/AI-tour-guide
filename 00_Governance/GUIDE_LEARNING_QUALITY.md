# GUIDE LEARNING & QUALITY GOVERNANCE

Status: Governance Baseline

## 1. Purpose

AI Tour Guide 不只帮助导游完成今天这一团，还要让导游每带完一团都比上一团更专业。

系统定位：私人教练，不是公开考官。

## 2. During-tour behavior

带团中避免频繁打断导游，尤其是驾驶状态。

仅以下情况允许优先私下提示：
- Critical safety issue
- legal/regulatory conflict
- official wildlife/conservation rule conflict
- high-confidence material factual error that may mislead visitors

普通改进建议进入下团后复盘。

## 3. Tour Review dimensions

至少包含：
1. Fact Accuracy
2. Narrative Quality
3. Visitor Answer Quality
4. Delivery Quality
5. Guide Experience Use
6. Visitor Engagement

总分不能替代分项证据。

## 4. Error classes

### Critical
安全、法律、官方保护规则等不能错。

### Factual
年份、人物、地点、数量、事件等事实错误。

### Narrative
时间轴断裂、因果不清、重复、支线未回主线等。

### Enhancement
不是错误，但存在更好的讲法、时机或经验。

## 5. Correction workflow

`Tour Record -> AI Review -> Evidence Check -> Guide Confirm/Reject/Edit -> Learning Candidate -> Reuse`

AI建议不得自动升级为永久Guide Experience。

导游可：
- accept
- reject
- modify
- mark as context-specific

## 6. Experience promotion

一条经验经过多次真实使用且表现稳定后，系统可以建议加入Guide Experience Pack。

升级前必须保留：
- source tour(s)
- author
- applicable conditions
- audience
- route/place scope
- confidence
- validation history

## 7. Guide Skill Profile

可以形成私人能力画像，例如：
- History
- Geography
- Nature
- Storytelling
- Visitor Q&A
- Tour Operations
- Photography Guidance
- Multilingual Delivery

默认不公开排名。

## 8. Acceptance

Learning能力只有在以下闭环成立后才算REAL：
1. 真实Tour Session产生记录
2. 系统识别至少一条可验证错误/改进项
3. 提供证据和原因
4. 导游确认/修改
5. 下一次Tour Session实际使用该学习结果
